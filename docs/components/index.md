# 电子元器件

> "认识元器件是电子制作的第一步，就像厨师必须认识食材。"

本章节涵盖从基础无源器件到射频专用器件的完整知识体系。

## 📚 内容导航

### [无源器件](/components/passive)
电阻、电容、电感的基础知识、参数解读、选型技巧。

### [有源器件](/components/active)
二极管、三极管、场效应管、集成电路的工作原理与应用。

### [射频器件](/components/rf)
巴伦、滤波器、低噪声放大器、混频器等射频电路核心器件。

### [检测与使用](/components/testing)
万用表、示波器、频谱仪的使用方法，元器件检测技巧。

## 🛒 推荐采购渠道

| 类型 | 推荐平台 | 特点 |
|-----|---------|------|
| 通用器件 | 立创商城、得捷电子 | 正品保证，参数详细 |
| 射频器件 |  Mini-Circuits、ADI | 专业射频器件 |
| 二手/拆机 | 淘宝、闲鱼 | 性价比高，需鉴别 |
| 进口器件 | Mouser、DigiKey | 品类齐全，交期稳定 |

## ⚡ 安全提醒

- 电解电容有极性，反接会爆炸
- 高压电容断电后仍带电，需放电处理
- 射频器件对静电敏感，操作时需防静电

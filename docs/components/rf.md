# 射频器件

射频电路工作频率高，需要专用器件来保证性能。

## 1. 巴伦 (Balun)

### 作用

Balun = **Bal**anced + **Un**balanced，实现平衡-不平衡转换：

```
平衡端 (对称)          不平衡端 (同轴)
    │                      │
   ┌┴┐                    ┌┴┐
   │ │──┐                │ │──┐
   │ │  │                │ │  │
   └┬┘  │                │ │  │
    │   │                └┬┘  │
    └───┘                 └───┘
```

### 常见类型

| 类型 | 原理 | 特点 | 应用 |
|-----|------|------|------|
| **变压器巴伦** | 变压器耦合 | 宽带，损耗小 | 多频段天线 |
| **扼流圈巴伦** | 共模扼流 | 简单，成本低 | 防止馈线辐射 |
| **1:4巴伦** | 阻抗变换 | 50Ω→200Ω | 长线天线 |
| **1:1巴伦** | 仅隔离 | 保持阻抗 | 偶极天线 |

### 自制磁环巴伦

```
材料: FT140-43 铁氧体磁环 (适合HF)
绕法: 双绞线绕 10-12 匝
阻抗: 约 1kΩ @ 10MHz
```

## 2. 滤波器 (Filter)

### 基本类型

| 类型 | 特性 | 应用 |
|-----|------|------|
| **低通 (LPF)** | 通过低频，衰减高频 | 发射机输出，抑制谐波 |
| **高通 (HPF)** | 通过高频，衰减低频 | 接收机前端 |
| **带通 (BPF)** | 通过特定频段 | 选频、抗干扰 |
| **带阻 (BRF)** | 衰减特定频段 | 陷波器 |

### LC滤波器设计

**7阶低通滤波器（截止频率 30MHz）**：

```
输入 ─┬─ L1 ─┬─ L2 ─┬─ L3 ─┬─ 输出
      │      │      │      │
     C1     C2     C3     C4
      │      │      │      │
     GND    GND    GND    GND

L1=L3=0.47μH, L2=0.68μH
C1=C4=100pF, C2=C3=220pF
```

### 陶瓷滤波器

- **455kHz**：AM中频滤波，用于超外差接收机
- **10.7MHz**：FM中频滤波
- **特点**：无需调整，体积小，一致性好

### 晶体滤波器

- **特点**：Q值极高（$10^4$-$10^6$），选择性极好
- **应用**：CW/SSB接收机窄带滤波
- **注意**：需精确匹配阻抗

## 3. 低噪声放大器 (LNA)

### 关键参数

| 参数 | 含义 | 优秀值 |
|-----|------|--------|
| **噪声系数 (NF)** | 放大器引入的噪声 | <1dB |
| **增益 (Gain)** | 放大倍数 | 10-30dB |
| **1dB压缩点** | 线性增益下降1dB的输入功率 | 越高越好 |
| **IP3** | 三阶交调截点 | 越高线性度越好 |

### 常用LNA器件

| 型号 | 频段 | NF | 增益 | 供电 |
|-----|------|-----|------|------|
| **SPF5189Z** | 0.05-4GHz | 0.6dB | 18dB | 5V |
| **LNA4ALL** | 0.01-4GHz | 0.8dB | 20dB | 5V |
| **PGA-103+** | DC-3GHz | 0.5dB | 20dB | 5V |
| **AD8302** | DC-2.7GHz | - | - | 5V |

### 设计要点

1. **阻抗匹配**：输入/输出必须50Ω匹配
2. **稳定性**：避免自激，$K > 1$
3. **偏置**：正确设置工作点
4. **屏蔽**：防止反馈和干扰

## 4. 混频器 (Mixer)

### 原理

将两个频率混合，产生和频与差频：

$$f_{IF} = |f_{RF} - f_{LO}|$$

```
RF输入 ──┐
         ├──┤ 混频器 ├── IF输出
LO输入 ──┘
```

### 常用混频器

| 类型 | 特点 | 应用 |
|-----|------|------|
| **二极管环形** | 无源，高IP3 | 高性能接收机 |
| **吉尔伯特单元** | 有源，集成度高 | IC内部 |
| **NE602/SA612** | 集成振荡器 | 简易超外差 |

## 5. 射频开关与衰减器

### PIN二极管开关

```
控制 ──┬──|>|──┬── RF通路
       │       │
      ─┴─     ─┴─
      GND     GND

正偏: 导通，RF通过
零偏/反偏: 截止，RF隔离
```

### 步进衰减器

| 衰减量 | 电阻值 (T型, 50Ω) |
|--------|-------------------|
| 3dB | R1=8.5Ω, R2=141.9Ω |
| 6dB | R1=16.6Ω, R2=66.9Ω |
| 10dB | R1=25.9Ω, R2=35.1Ω |
| 20dB | R1=40.9Ω, R2=10.1Ω |

## 6. 射频连接器

| 类型 | 频率 | 特点 | 应用 |
|-----|------|------|------|
| **SMA** | DC-18GHz | 小型，螺纹 | 常用 |
| **BNC** | DC-4GHz | 卡口，易插拔 | 测试设备 |
| **N型** | DC-11GHz | 大功率，耐用 | 基站、天线 |
| **UHF (PL259)** | DC-300MHz | 大，易焊接 | HF电台 |
| **F型** | DC-1GHz | 螺纹，便宜 | 有线电视 |

> ⚠️ **连接技巧**：
> - 使用力矩扳手，SMA约0.9N·m
> - 保持连接器清洁
> - 避免弯折同轴电缆

# 检测与使用

## 1. 万用表使用

### 基本功能

| 功能 | 量程/注意 | 应用 |
|-----|----------|------|
| **直流电压** | 选合适量程，红正黑负 | 电源检测 |
| **交流电压** | 注意是有效值 | 市电检测 |
| **直流电流** | 串联接入，注意极性 | 功耗测量 |
| **电阻** | 断电测量，注意手不要同时接触两端 | 元件检测 |
| **二极管** | 显示正向压降 | 二极管/通断检测 |
| **通断** | 蜂鸣提示 | 线路通断 |
| **电容** | 注意极性（电解电容） | 容量检测 |

### 电阻检测技巧

```
1. 断电！确保电路无电
2. 选择电阻档（Ω）
3. 如果显示"OL"或"1"，表示超量程或开路
4. 如果显示接近0，表示短路
5. 测量时至少一只手不接触表笔金属部分
```

### 电容检测

- **容量测量**：直接读数，对比标称值
- **漏电检测**：用电阻档，充电后应逐渐变为开路
- **电解电容**：注意极性，红表笔接正极

## 2. 示波器使用

### 基本操作

```
1. 探头校准：连接校准输出，调整补偿电容
2. 设置耦合：DC（含直流）、AC（隔直）、GND（零电平）
3. 调节时基：显示1-2个周期为宜
4. 调节幅度：占屏幕2/3高度
5. 触发设置：边沿触发，选择合适电平
```

### 射频测量要点

| 测量项 | 设置 | 注意 |
|--------|------|------|
| **频率** | 时基微调校准 | 使用光标或测量功能 |
| **幅度** | 注意探头衰减比 | 1X/10X |
| **波形** | 采样率 > 5倍信号频率 | 避免混叠 |
| **调制** | 开启FFT功能 | 观察频谱 |

### 简易射频探头

没有高频探头时，可用自制探头：

```
同轴电缆 ──┬── 100Ω电阻 ── 探针
           │
          1nF电容 ── GND夹
```

用于粗略观察射频波形。

## 3. 频谱仪使用

### 基本参数设置

| 参数 | 含义 | 设置建议 |
|-----|------|---------|
| **中心频率 (CF)** | 显示中心 | 设为信号频率 |
| **扫宽 (Span)** | 显示频率范围 | 根据信号带宽设置 |
| **分辨率带宽 (RBW)** | 频率分辨能力 | 越小越精确，扫描越慢 |
| **视频带宽 (VBW)** | 噪声平滑 | 通常 = RBW |
| **参考电平 (Ref)** | 顶部对应功率 | 设为略大于信号功率 |

### 常见测量

```
1. 发射功率：Marker读取峰值
2. 谐波抑制：观察谐波与基波差值（应 > 40dB）
3. 杂散发射：全频段扫描，检查非预期信号
4. 占用带宽：-6dB或-26dB带宽测量
```

## 4. 元器件检测速查

### 二极管

| 测试 | 正常 | 损坏 |
|------|------|------|
| 正向 | 0.5-0.7V（硅）/ 0.2-0.3V（锗/肖特基） | 开路或无穷大 |
| 反向 | OL（超量程） | 短路或低阻 |

### 三极管

```
NPN型检测（以2N3904为例）:
1. 基极-发射极：正向 0.7V，反向 OL
2. 基极-集电极：正向 0.7V，反向 OL
3. 集电极-发射极：双向 OL（截止时）

如果CE间有阻值，可能击穿损坏。
```

### MOSFET

```
注意：MOSFET对静电敏感！

检测步骤：
1. 三个脚短路放电
2. 栅源间应开路（无穷大）
3. 给栅极充电（表笔触碰），DS间应导通
4. 再次短路放电，DS间应截止
```

### 电感

- **直流电阻**：应很小（几Ω到几百Ω）
- **开路**：无穷大（线圈断裂）
- **短路匝间**：电阻异常低，电感量下降

### 变压器

```
检测步骤：
1. 各绕组直流电阻：应符合匝数比
2. 绕组间绝缘：应无穷大
3. 绕组对铁芯：应无穷大
4. 加电测试：输出电压应符合匝数比
```

## 5. 射频功率测量

### 通过式功率计

```
发射机 ──[功率计]── 天线
          │
        显示:
        - 正向功率 (Forward)
        - 反射功率 (Reflected)
        - VSWR (计算值)
```

### 简易功率测量

没有功率计时，可用**假负载+示波器**：

```
发射机 ── 50Ω假负载 ── 示波器探头

功率计算：P = V² / (2 × R) = V² / 100
（V是峰峰值的一半，即Vp）
```

### 常见功率单位换算

| dBm | mW | W | 备注 |
|-----|-----|-----|------|
| 0 | 1 | 0.001 | 基准 |
| 10 | 10 | 0.01 | |
| 20 | 100 | 0.1 | |
| 27 | 500 | 0.5 | 手持对讲机 |
| 30 | 1000 | 1 | 1W |
| 37 | 5000 | 5 | 车载台 |
| 40 | 10000 | 10 | 基地台 |
| 50 | 100000 | 100 | 短波电台 |

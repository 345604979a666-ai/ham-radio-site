# ⭐⭐ 短波天线

> "天线是无线电系统的灵魂。一根好天线胜过一台好电台。"

架设你的第一根HF天线，开始短波通联之旅。

## 📋 项目信息

| 项目 | 短波天线 |
|-----|---------|
| **难度** | ⭐⭐ 进阶 |
| **成本** | 50-200元 |
| **时间** | 1-2天 |
| **工具** | 电烙铁、万用表、钳子、梯子 |
| **场地** | 需要一定空间（至少10m×5m） |

## 🔧 天线选择

### 根据条件选择

| 条件 | 推荐天线 | 频段 | 特点 |
|------|---------|------|------|
| 空间小(<10m) | 端馈长线 | 多频段 | 任意长度，NVIS |
| 有树/支撑点 | 倒V天线 | 单/多频段 | 架设简单，全向 |
| 有转向器 | 八木天线 | 单频段 | 高增益，定向 |
| 阳台/室内 | 磁环天线 | 单频段 | 小型，低噪声 |
| 临时架设 | 便携长线 | 多频段 | 快速部署 |

## 📐 方案：倒V天线（推荐初学者）

### 结构

```
                    支撑点（树/杆，高8-12m）
                         │
                    ┌────┴────┐
                    │         │
                   /                             /                              /                               /                                /    馈电点                      /    ┌───┐                        /     │   │                        /      │巴伦│                        /       │1:1 │                        /        └───┘                        /             │                        /              │ 50Ω同轴电缆           /               │                      /               GND                    /                                       地锚                                  地锚
    （绝缘子）                          （绝缘子）
```

### 尺寸计算

以40m波段（7MHz）为例：

```
半波长 = 150 / f(MHz) = 150 / 7 = 21.4米
考虑缩短率(5%): 实际长度 = 21.4 × 0.95 = 20.3米

每臂长度 = 20.3 / 2 = 10.15米

架设角度: 90°-120°（顶角）
          角度越小，阻抗越低，方向性越强
```

## 📐 制作步骤

### 步骤1：制作巴伦（可选自制）

```
FT140-43磁环巴伦:

材料:
- FT140-43 铁氧体磁环 × 1
- 0.5mm漆包线或双绞线

绕法:
1. 双绞线穿过磁环
2. 绕10-12匝
3. 一端接天线，另一端接同轴

阻抗: 约1kΩ @ 7MHz
功率: 可承受100W+
```

### 步骤2：裁剪天线振子

```
根据目标频段裁剪:

40m波段 (7MHz):
总长度 = 150/7 × 0.95 = 20.3米
每臂 = 10.15米

20m波段 (14MHz):
总长度 = 150/14 × 0.95 = 10.2米
每臂 = 5.1米

80m波段 (3.5MHz):
总长度 = 150/3.5 × 0.95 = 40.7米
每臂 = 20.4米
```

### 步骤3：安装绝缘子

```
在振子两端安装绝缘子:

    振子 ──[绝缘子]── 拉绳 ── 地锚

绝缘子作用:
- 电气隔离天线与支撑结构
- 防止拉绳感应电流
```

### 步骤4：架设天线

```
架设流程:

1. 选择支撑点（树、杆、建筑物）
   高度: 8-15米为宜

2. 安装支撑绳
   从支撑点垂下，连接巴伦

3. 展开振子
   两臂呈倒V形展开
   底角距地面2-3米（安全高度）

4. 固定地锚
   拉紧振子，用绝缘子连接地锚

5. 连接馈线
   巴伦输出端连接50Ω同轴电缆

6. 接地
   同轴屏蔽层在电台端接地
```

### 步骤5：调试

```
使用天线分析仪或驻波比表:

1. 测量各频段VSWR:
   目标: VSWR < 2.0
   理想: VSWR < 1.5

2. 调整方法:
   - VSWR偏高: 调整振子长度（剪短或加长）
   - 谐振频率偏低: 剪短振子
   - 谐振频率偏高: 加长振子

3. 修剪公式:
   每剪短1%，频率升高约1%

   例如: 7MHz谐振在6.8MHz
   需剪短: (7-6.8)/6.8 × 100% = 3%
   20.3米 × 3% = 0.6米
```

## 📊 多频段使用

### 单根天线覆盖多频段

倒V天线在基频的**奇数倍频**上也能工作：

| 基频 | 可用频段 | 谐波次数 |
|------|---------|---------|
| 40m (7MHz) | 40m, 20m, 15m, 10m | 1, 3, 5, 7 |
| 80m (3.5MHz) | 80m, 40m, 30m, 20m, 17m | 1, 2, 3, 4, 5 |

> 💡 **技巧**：用40m天线可覆盖40/20/15/10m四个主要业余频段！

### 使用天线调谐器

如果VSWR不理想，可使用天线调谐器（ATU）：

```
电台 ──[ATU]──[巴伦]──[天线]

ATU作用:
- 将天线阻抗变换为50Ω
- 保护电台输出级
- 扩展可用频段
```

## 🔧 进阶方案

### 端馈半波天线 (EFHW)

```
优点: 只需一个支撑点，末端馈电

结构:
    支撑点
       │
    ┌──┴──┐
    │     │
    │ 振子│  约半波长
    │     │
    └──┬──┘
       │
    [49:1巴伦]
       │
    [同轴电缆]
       │
      电台

49:1巴伦将高阻抗(~2500Ω)变换为50Ω
```

### 多波段端馈天线

使用**陷波器(Trap)**实现多波段：

```
    支撑点
       │
    ┌──┴────────────────────────┐
    │                           │
    │  10m陷波器   20m陷波器    │
    │  ┌──┐       ┌──┐          │
    │  │LC│       │LC│          │
    │  └──┘       └──┘          │
    │                           │
    └───────────────────────────┘

    10m波段: 电流在第一个陷波器处被阻断
    20m波段: 电流在第二个陷波器处被阻断
    40m波段: 使用全长振子
```

### 环形天线 (Magnetic Loop)

适合空间有限的环境：

```
    ┌──────────────┐
    │              │
    │    环形      │  周长 = 1/4 ~ 1/5波长
    │   (铜管)     │  例如40m波段: 约3-4米周长
    │              │
    └──────┬───────┘
           │
       [可变电容]  高压型，耐压>1000V
           │
       [耦合环]   小环，直径为1/5主环
           │
          电台

    特点: Q值极高，带宽极窄，需精细调谐
```

## 🛡️ 安全与法规

### 架设安全

| 项目 | 要求 |
|------|------|
| **高度** | 底角距地面>2.5m，防止触碰 |
| **距离** | 远离高压线>2倍倒伏距离 |
| **防雷** | 安装避雷器，雷雨天气断开 |
| **结构** | 考虑风载荷，使用拉线加固 |

### 法规合规

- 发射功率符合操作证等级限制
- 频率在业余频段内
- 定期发送呼号（至少每10分钟）
- 保留通联日志

## 🐛 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| VSWR高 | 长度不准 | 精确测量并修剪 |
| 某频段VSWR高 | 不在谐波点上 | 使用天线调谐器 |
| 接收噪声大 | 附近有干扰源 | 更换位置或加滤波器 |
| 方向性不好 | 架设高度不够 | 升高支撑点 |
| 巴伦发热 | 功率过大或共模电流 | 检查巴伦额定功率，加共模扼流圈 |

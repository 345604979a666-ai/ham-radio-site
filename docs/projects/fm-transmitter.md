## 🔧 工作原理

### 框图

```
音频输入 ──→ 预加重 ──→ 调制器 ──→ 振荡器 ──→ 缓冲放大 ──→ 天线
                │
                └── 频率稳定（可选PLL）
```

1. **音频处理**：预加重提升高频，改善信噪比
2. **调制**：音频信号改变振荡频率（FM）
3. **振荡**：LC或晶体振荡产生载波
4. **缓冲**：隔离振荡器与天线，稳定频率
5. **发射**：通过天线辐射电磁波

### FM调制深度

$$\Delta f = k_f \times V_{audio}$$

- $\Delta f$：频偏（最大75kHz为广播标准）
- $k_f$：调制灵敏度
- 带宽：$BW \approx 2(\Delta f + f_{max})$

#### 制作步骤

**步骤1：准备PCB**

```
在洞洞板上规划布局:

    ┌─────────────────────────┐
    │  [BH1417F]              │
    │  ┌──────────┐           │
    │  │          │  [晶振]   │
    │  │          │           │
    │  │          │  [电感]   │
    │  └──────────┘           │
    │                         │
    │  [话筒]  [电容] [电阻]  │
    │                         │
    │  [电源接口]  [天线接口]  │
    └─────────────────────────┘
```

**步骤2：焊接IC**

1. 先焊接BH1417F，注意引脚顺序（缺口向左，逆时针数）
2. 焊接晶振（尽量靠近IC引脚6和7）
3. 焊接电感和电容

**步骤3：焊接外围电路**

1. 焊接话筒偏置电路（R1、C3）
2. 焊接电源退耦电容（C2、C4）
3. 焊接输出匹配电路（L1、C1）

**步骤4：连接天线**

```
天线长度计算:

λ = c / f = 300 / 100 = 3米 (100MHz)
1/4波长 = 0.75米 = 75cm

使用75cm导线作为天线:

    发射器 ──[75cm导线]──
                          │
                         (垂直向上)
```

**步骤5：上电测试**

1. 连接9V电池或5V电源
2. 用FM收音机在88-108MHz搜索信号
3. 调整收音机频率，找到发射频率
4. 对着话筒说话，检查接收效果

## 🔧 调试技巧

### 频率调整

BH1417F的频率由PLL控制，通过DATA和CLK引脚设置：

```
频率设置 (以100MHz为例):

参考频率 = 7.6MHz / 32 = 237.5kHz
分频比 = 100MHz / 237.5kHz = 421.05

实际分频比取整为421:
实际频率 = 421 × 237.5kHz = 99.9875MHz

DATA和CLK引脚通常连接单片机或专用设置电路
```

### 功率调整

- **增大功率**：提高供电电压（不超过IC最大额定值）
- **减小功率**：降低电压或增加衰减
- **注意**：功率过大会导致频率不稳定或谐波增大

### 音质优化

| 问题 | 解决方法 |
|------|---------|
| 声音小 | 增大话筒偏置电阻或换更灵敏的话筒 |
| 失真 | 减小音频输入幅度，检查预加重电路 |
| 噪声大 | 改善电源滤波，缩短音频引线 |
| 频率漂移 | 确保晶振质量，改善散热 |

## 📊 性能测试

### 简易测试方法

```
1. 频率准确度:
   用FM收音机接收，对比电台频率
   误差应 < 100kHz

2. 发射功率估算:
   在1米距离用收音机接收
   如果信号清晰无噪声，功率约1-10mW

3. 覆盖范围:
   户外开阔地测试
   典型值: 50-200米

4. 谐波检查:
   在200MHz、300MHz等倍频处检查
   应无明显信号（>40dB抑制）
```

## 🚀 进阶改进

### 增加PLL频率合成

使用单片机（如Arduino）控制BH1417F的频率：

```cpp
// Arduino控制BH1417F频率示例
void setFrequency(float freq) {
    int divider = freq * 1000 / 237.5; // 237.5kHz参考
    // 通过DATA和CLK发送分频比
    for(int i = 0; i < 16; i++) {
        digitalWrite(DATA, (divider >> i) & 1);
        digitalWrite(CLK, HIGH);
        delayMicroseconds(1);
        digitalWrite(CLK, LOW);
    }
}
```

### 增加功率放大

```
BH1417F输出 ──[匹配网络]──[2SC2053/2N4427]──[低通滤波]──[天线]

可增加功率到100mW-1W
注意: 需符合法规功率限制！
```

### 增加立体声编码

使用BA1404或BH1417F内置MPX功能，实现立体声发射。

## 🐛 常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 无信号 | 晶振未起振 | 检查晶振和负载电容 |
| 频率不准 | 晶振频率偏差 | 更换晶振或调整负载电容 |
| 有载波无调制 | 音频未输入 | 检查话筒和耦合电容 |
| 声音失真 | 过调制 | 减小音频幅度 |
| 频率漂移 | 温度影响 | 使用温度补偿或PLL |
| 谐波大 | 无滤波器 | 增加低通滤波器 |

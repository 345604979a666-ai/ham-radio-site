# ⭐ 矿石收音机

> "不需要电池，不需要电源，仅靠天线就能听到远方的声音。"

矿石收音机是最简单的无线电接收机，也是理解无线电原理的最佳起点。

## 🔧 工作原理

### 最简单的矿石收音机

```
天线 ──┬── 线圈 ──┬── 二极管 ──┬── 耳机
       │          │            │
      GND      可变电容      GND
```

1. **天线**：接收空中电磁波，感应出微弱电流
2. **LC调谐回路**：线圈+可变电容，选择特定频率
3. **检波二极管**：从高频信号中提取音频信号
4. **耳机**：将音频电信号转换为声音

### 调谐原理

$$f = \frac{1}{2\pi\sqrt{LC}}$$

- 改变电容C → 改变谐振频率 → 选择不同电台
- 中波广播频段：530-1600kHz

## 📐 制作步骤

### 步骤1：绕制线圈

```
在磁棒上绕制线圈:

    ┌────────────────────────┐
    │  ████████████████████    │  ← 磁棒
    │    ╭────────────────╮    │
    │    │  0.5mm漆包线   │    │
    │    │  绕60-80匝     │    │
    │    │  紧密排列      │    │
    │    ╰────────────────╯    │
    └────────────────────────┘

    从一端开始，向另一端密绕
    匝数越多，电感量越大，覆盖低频
```

**绕制要点**：
- 匝数：60-80匝（覆盖中波全频段）
- 线径：0.3-0.5mm漆包线
- 抽头：在约20匝处抽头（接二极管）
- 磁棒：中波专用锰锌铁氧体磁棒

### 步骤2：组装电路

```
         天线 (10-20m导线)
              │
              ├──────────────┐
              │              │
           线圈L1          可变电容C1
         ┌───────┐         ┌───┐
    抽头20匝   80匝        │   │
         │      │          └───┘
         ├──────┤           │
         │      │          GND
    二极管D1    │
    ┌──|>|──┐   │
    │       │   │
    └──┬────┘   │
       │        │
    耳机(2kΩ)   │
       │        │
      GND      GND
       │
      地线 (接地)
```

**接线说明**：
1. 线圈一端接天线
2. 线圈另一端和可变电容一端接地
3. 可变电容另一端接线圈（与天线端相对）
4. 二极管正极接线圈抽头（约20匝处）
5. 二极管负极接耳机一端
6. 耳机另一端接地

### 步骤3：架设天线

```
天线架设建议:

    房屋
    ┌────────┐
    │        │
    │   收音机│
    │        │
    └────────┘
       │
       │ 引线
       │
    ┌──┴──────────────────┐
    │    10-20m 水平天线    │
    │    (尽量远离金属)     │
    └───────────────────────┘
       │
       │ 绝缘子
       │
      GND (地线)
```

**天线要点**：
- 长度：10-20米效果较好
- 高度：越高越好，远离金属物体
- 方向：东西向架设，接收南北向电波（中波垂直极化）
- 地线：接入暖气管、水管或埋地金属板

### 步骤4：调试

1. **检查接线**：确保所有连接牢固，无短路
2. **转动电容**：缓慢旋转可变电容，寻找电台
3. **调整方向**：转动磁棒方向，寻找最佳接收角度
4. **优化天线**：尝试不同长度和方向

## 🔊 预期效果

| 条件 | 可收听到 |
|-----|---------|
| 天线10m+良好接地 | 本地强台清晰 |
| 天线20m+高楼/郊区 | 多个电台，部分弱台 |
| 夜间+长天线 | 可能收到远距离电台（天波传播） |

## 🐛 常见问题

### 完全无声

| 检查项 | 解决方法 |
|--------|---------|
| 耳机是否高阻？ | 普通耳机（32Ω）需要加音频变压器或改用高阻耳机 |
| 二极管方向？ | 尝试反接二极管 |
| 天线是否有效？ | 加长天线，改善接地 |
| 线圈匝数？ | 增加或减少10匝试试 |

### 声音微弱

- 加长天线
- 改善接地（接水管或埋地金属板）
- 尝试不同的二极管（锗管优于硅管）
- 检查线圈是否松散，应紧密排列

### 串台严重

- 线圈增加匝数（提高Q值）
- 使用更好的可变电容（空气介质优于薄膜）
- 调整磁棒方向

## 🚀 进阶改进

### 加音频放大器

```
矿石收音机 ──→ 音频变压器 ──→ LM386放大器 ──→ 普通耳机/喇叭
```

使用LM386制作简单音频放大器，可用普通耳机听到更大音量。

### 多波段矿石机

增加线圈抽头或使用多个线圈，覆盖短波频段：

| 波段 | 线圈匝数 | 可变电容 |
|-----|---------|---------|
| 中波 | 60-80匝 | 365pF |
| 短波3-5MHz | 30-40匝 | 365pF |
| 短波7MHz | 15-20匝 | 100pF |

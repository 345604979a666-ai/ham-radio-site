# 电子小制作

> "最好的学习方式就是动手做。"

从最简单的矿石收音机开始，逐步挑战更复杂的项目。每个项目都包含：原理图、BOM清单、制作步骤、调试技巧和常见问题。

## 📚 项目导航

### ⭐ 入门项目

#### [矿石收音机](/projects/crystal-radio)
不需要电源，仅靠天线接收信号。最纯粹的无线电体验。

### ⭐⭐ 进阶项目

#### [FM发射器](/projects/fm-transmitter)
制作一个小功率FM发射器，把你的声音送上电波。

#### [短波天线](/projects/hf-antenna)
架设你的第一根HF天线，开始短波通联。

### ⭐⭐⭐ 高级项目

#### [SDR接收机](/projects/sdr-receiver)
使用RTL-SDR，探索软件定义无线电的世界。

## ⚠️ 安全须知

1. **焊接安全**：通风良好，避免吸入焊锡烟雾
2. **电气安全**：高压电容放电后再操作
3. **射频安全**：发射设备连接假负载或天线后再上电
4. **法规遵守**：发射项目需符合当地法规，功率和频率需合规

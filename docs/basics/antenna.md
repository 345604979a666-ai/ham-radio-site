# 天线基础

## 天线的作用

天线是**导波系统与自由空间**的转换器：
- **发射**：将馈线中的导行电磁波转换为自由空间的辐射电磁波
- **接收**：将空间电磁波转换为馈线中的电信号

> 💡 **互易定理**：同一根天线，发射和接收特性完全相同。

## 基本天线类型

### 1. 半波振子 (Dipole)

最经典的天线，总长度约半个波长：

```
          ┌─────────────────────┐
          │      馈电点         │
          │        ●            │
          │       /\           │
          │      /  \          │
          │     /    \         │
          │    /      \        │
          │   /        \       │
          │  /          \      │
          │ /            \     │
          │/              \    │
          └─────────────────────┘
          总长 ≈ λ/2 = 150/f(MHz) 米
```

- **阻抗**：约 73Ω（谐振时）
- **辐射方向**：垂直于振子轴线的面包圈形
- **增益**：2.15 dBi（相对于各向同性天线）

### 2. 垂直单极天线 (Monopole / GP)

地面作为"镜像"，只需 1/4 波长：

```
                    │
                    │  辐射体 (λ/4)
                    │
                    │
          ──────────┴──────────  地网/地面
```

- **阻抗**：约 36Ω（需加地网或接地系统）
- **辐射**：水平面全向，垂直面呈"8"字形
- **应用**：车载天线、基地台、广播发射

### 3. 八木天线 (Yagi-Uda)

高增益定向天线，由多个振子组成：

```
          反射器    激励振子    引向器
            │         │          │
          ┌─┐       ┌─┐        ┌─┐
          │ │       │ │        │ │
          │ │       │ │        │ │
          │ │       │ │        │ │
          └─┘       └─┘        └─┘

          间距: 0.1-0.25 λ
```

- **反射器**：比激励振子长 5%，位于后方
- **引向器**：比激励振子短 5%，位于前方（可多根）
- **增益**：每增加一个引向器，增益约增加 1dB
- **典型配置**：3单元（约7dBi）、5单元（约10dBi）

### 4. 环形天线 (Loop)

```
          ┌────────────┐
          │            │
          │            │
          │            │
          │            │
          └────────────┘

          小环: 电小天线，用于接收/测向
          大环: 周长≈1λ，全向辐射
```

## 关键参数

### 驻波比 (SWR / VSWR)

衡量天线与馈线阻抗匹配程度：

$$VSWR = \frac{1 + |\Gamma|}{1 - |\Gamma|}$$

| VSWR | 反射功率 | 状态 |
|------|---------|------|
| 1.0 | 0% | 完美匹配 |
| 1.5 | 4% | 良好 |
| 2.0 | 11% | 可接受 |
| 3.0 | 25% | 较差，可能损坏发射机 |

> ⚠️ **发射机保护**：大多数现代电台在 VSWR > 3 时会自动降低功率或保护关机。

### 增益 (Gain)

- **dBi**：相对于各向同性辐射器（理论球体）
- **dBd**：相对于半波振子（dBd = dBi - 2.15）

### 波束宽度

- **-3dB波束宽度**：功率降至一半的角度范围
- 八木天线通常 30°-60°，全向天线 360°

## 常见业余天线速查

| 天线类型 | 适用频段 | 增益 | 特点 |
|---------|---------|------|------|
| 倒V天线 | HF | 2-3dBi | 架设简单，多频段可用 |
| 端馈长线 | HF | 2-3dBi | 随机长度，NVIS通信 |
| 垂直GP | HF/VHF | 1-2dBi | 全向，需良好地网 |
| 八木 | VHF/UHF | 7-15dBi | 定向，需转向器 |
| 螺旋天线 | UHF/SHF | 10-15dBi | 圆极化，卫星通信 |
| 抛物面 | SHF | 20-30dBi | 极高增益，卫星/微波 |

## 🛠️ 天线制作要点

### 材料选择
- **振子**：铜线、铝管、不锈钢（避免铁磁性材料）
- **支撑**：PVC管、玻璃纤维杆、木杆
- **绝缘**：陶瓷、塑料、玻璃（避免潮湿木材）

### 安全提醒
- **远离高压线**：至少保持 2 倍倒伏距离
- **防雷**：安装避雷针和接地系统
- **结构安全**：考虑风载荷，使用拉线加固

# 电磁波与频段

## 什么是电磁波？

电磁波是**电场**和**磁场**交替变化并在空间中传播的波动。不需要介质，可以在真空中传播，速度为光速：

$$c = 3 \times 10^8 \text{ m/s} = 300,000 \text{ km/s}$$

### 核心公式

$$c = f \times \lambda$$

- $f$ = 频率（Hz）
- $\lambda$ = 波长（m）
- $c$ = 光速（$3 \times 10^8$ m/s）

> 💡 **记忆口诀**：频率越高，波长越短。300MHz 对应 1米波长。

## 电磁波的传播方式

| 传播方式 | 适用频段 | 特点 |
|---------|---------|------|
| **地波** | LF/MF（长波/中波） | 沿地面传播，稳定但衰减大 |
| **天波** | HF（短波 3-30MHz） | 经电离层反射，可实现远距离通信 |
| **视距传播** | VHF/UHF（超短波） | 直线传播，受地形和建筑物影响 |
| **散射传播** | VHF/UHF | 利用对流层散射，超视距通信 |

### 电离层与天波

电离层位于地面 60-400km 高度，分为 D、E、F1、F2 层：

- **白天**：D 层吸收强，高频段（14MHz+）才能穿透到达 F 层反射
- **夜晚**：D 层消失，低频段也能反射，但 F 层升高，最高可用频率（MUF）降低

> ⚠️ **太阳活动影响**：太阳黑子活动高峰期（约11年周期），电离层电子密度增加，HF 通信条件更好。

```

```

## 🧪 动手实验：估算波长

找一根导线，按以下公式剪成特定长度，就是对应频率的**半波振子天线**（实际需考虑缩短率）：

$$\text{长度}(\text{m}) = \frac{150}{f(\text{MHz})}$$

例如 7MHz 的半波振子：$150 / 7 = 21.4$ 米

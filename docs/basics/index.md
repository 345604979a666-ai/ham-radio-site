# 无线电基础

> "如果你不能用简单的语言解释它，说明你还没真正理解它。" —— 理查德·费曼

本章节从最基本的物理概念出发，带你逐步建立无线电通信的完整知识体系。

## 📚 内容导航

### [电磁波与频段](/basics/electromagnetic)
电磁波的本质、传播方式、频谱划分，以及为什么不同频段有不同特性。

### [调制与解调](/basics/modulation)
AM、FM、SSB、CW 等调制方式原理，用动画和图表直观理解信号变换。

### [天线基础](/basics/antenna)
天线工作原理、常见类型、阻抗匹配、驻波比（SWR）详解。

### [业余频段划分](/basics/bands)
中国业余无线电频段一览表，含各频段传播特性和常用模式。

## 🎯 学习建议

1. **先看**电磁波与频段（建立基础概念）
2. **再学**调制与解调（理解信号如何承载信息）
3. **结合**天线基础（明白信号如何发射和接收）
4. **最后**查看频段划分（知道在哪里可以合法操作）

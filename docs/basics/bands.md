# 业余频段划分与法规

## 中国业余无线电操作证分类

根据工信部2024年发布的《业余无线电台管理办法》citeweb_search:8#16，操作证分为A、B、C三类：

| 类别 | 频段权限 | 功率限制 | 考试要求 |
|-----|---------|---------|---------|
| **A类** | 30-3000 MHz（VHF/UHF） | ≤25W | 初次申请，题库365题，考30题对25题通过 |
| **B类** | 全部业余频段（含HF短波） | 30MHz以下≤100W，30MHz以上≤25W | A证满6个月，题库689题 |
| **C类** | 全部业余频段 | 30MHz以下≤1000W，30MHz以上≤25W | B证满2年且执照满18个月 |

> ⚠️ **重要**：2024年新规允许**未成年人**设置30-3000MHz、功率≤25W的业余电台！citeweb_search:8#16

## 中国业余频段详细划分

### HF 短波频段（B类及以上）

| 波段 | 频率范围 | 常用模式 | 传播特性 |
|-----|---------|---------|---------|
| 160m | 1.800-2.000 MHz | CW | 夜间地波+天波，噪声大 |
| 80m | 3.500-3.900 MHz | CW/SSB/Digital | 夜间通信主力，国内通联 |
| 60m | 5.3515-5.3665 MHz | CW/SSB | 2018年新增，功率≤15W，次要业务 |
| 40m | 7.000-7.200 MHz | CW/SSB/Digital | **DX黄金频段**，全天候远距离 |
| 30m | 10.100-10.150 MHz | CW/Digital | 仅限窄带，功率≤200W |
| 20m | 14.000-14.350 MHz | CW/SSB/Digital | **DX最佳频段**，白天开放 |
| 17m | 18.068-18.168 MHz | CW/SSB/Digital | 太阳活动期效果好 |
| 15m | 21.000-21.450 MHz | CW/SSB | 太阳活动期全球通联 |
| 12m | 24.890-24.990 MHz | CW/SSB/Digital | 太阳活动期开放 |
| 10m | 28.000-29.700 MHz | CW/SSB/FM/Digital | 太阳活动期效果极佳 |

### VHF/UHF 超短波频段（A类及以上）

| 波段 | 频率范围 | 常用模式 | 应用 |
|-----|---------|---------|------|
| 6m | 50-54 MHz | SSB/CW/FM | 突发E层传播，本地+DX |
| 2m | 144-146 MHz | FM/SSB/CW/Digital | **本地通信主力**，中继台 |
| 70cm | 430-440 MHz | FM/Digital | 本地通信，卫星通信 |
| 23cm | 1240-1300 MHz | FM/Digital | 微波入门，EME通信 |
| 13cm | 2300-2450 MHz | FM/Digital | 卫星通信 |

> 📢 **注意**：部分地区（如上海）对146-148MHz、430-440MHz频段有暂缓受理政策，请查询当地无线电管理机构最新通知。citeweb_search:8#8

## 考试与申请流程

### 1. 考取操作证

1. **报名**：关注当地无线电管理机构或CRAC官网公告
2. **备考**：使用题库刷题（推荐 [智谱APP](http://www.cqid.cn/) 或在线模拟考试）
3. **考试**：免费参加，机考或纸笔
4. **领证**：通过后领取操作证（纸质/电子均可）

### 2. 申请电台执照

取得操作证后，向当地无线电管理机构申请：

1. **准备材料**：
   - 操作证复印件
   - 设备型号核准证明（查询 [工信部无线电发射设备型号核准](https://www.miit.gov.cn/)）
   - 设备照片和技术参数
   - 设台申请表

2. **设备要求**：
   - 必须取得型号核准（CMIIT ID）
   - 核准证载明的频率范围必须包含业余业务频段
   - 自制/改装设备需符合国家标准且频率仅限业余频段

3. **领取执照**：获得呼号（如 **BH4XXX**）

### 3. 呼号规则

| 前缀 | 区域 |
|-----|------|
| BA-BG | 中国大陆 |
| BH4 | 上海 |
| BH5 | 江苏 |
| BH6 | 浙江 |
| BH7 | 福建 |
| BH8 | 广东 |
| BI1 | 北京 |
| BJ1 | 北京（部分） |
| BR5 | 江苏（中继台等） |

> 📞 呼号查询：[CRAC呼号查询系统](http://www.crac.org.cn)

## ⚖️ 法律法规要点

根据《中华人民共和国无线电管理条例》和《业余无线电台管理办法》：

1. **无线电频谱资源属于国家所有**
2. **禁止擅自设置、使用无线电台**
3. **禁止干扰无线电业务**
4. **业余电台仅限个人技术学习和交流，禁止商业用途**
5. **通联必须使用明码，禁止加密**
6. **必须定期发送呼号（至少每10分钟）**
